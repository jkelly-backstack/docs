# Organization Services Screenshots

This directory should contain screenshots for the Organization Services documentation.

## Required Screenshots

Please capture and add the following screenshots from `/admin/tools`:

1. **add-service-dropdown.png** - The "Add Service" dropdown menu showing both options:
   - Install NPM Package
   - Add Remote Server

2. **npm-package-dialog.png** - The NPM Package installation dialog showing:
   - Package name input field
   - Version input field
   - Environment variables section
   - Install button

3. **remote-server-dialog.png** - The Remote Server connection dialog showing:
   - Server name input
   - Server URL input
   - Transport type selection (SSE/HTTP Streamable)
   - Authentication options
   - Connect/Authorize button

4. **service-status-badges.png** - Examples of different service status badges:
   - Available (green)
   - Installing (blue, pulsing)
   - Needs Configuration (gray)
   - Error (red)

5. **service-card-menu.png** - The three-dot menu on a service card showing options like:
   - Install Status
   - Configure
   - Retry Installation
   - Uninstall/Remove

## How to Add Screenshots

1. Navigate to `/admin/tools` in the Backstack web interface
2. Capture screenshots of the UI elements listed above
3. Save them with the specified filenames in this directory
4. Update the documentation to reference these images

## Image Guidelines

- Use PNG format for best quality
- Crop to show only relevant UI elements
- Include enough context to understand what's being shown
- Use consistent browser window size for all screenshots
