# Workspaces

Backstack Workspaces help you organize tools, resources, and team access in logical groups.

## What are Workspaces?

A workspace is a collection of:
- **Tools** - Executable actions and integrations
- **Resources** - Data sources and context
- **Members** - Team members with specific permissions
- **Settings** - Configuration and access controls

## Creating a Workspace

1. Log in to [Backstack](https://app.backstack.io)
2. Click **Create Workspace**
3. Enter a name and description
4. Configure visibility and permissions
5. Click **Create**

## Workspace Settings

### Visibility

- **Private** - Only visible to members you invite
- **Organization** - Visible to all organization members

### Permissions

Control who can:
- View workspace tools and resources
- Add or modify tools
- Invite members
- Delete the workspace

## Managing Members

Add team members to a workspace:

1. Open the workspace
2. Go to **Members** tab
3. Click **Add Member**
4. Select user and assign permissions
5. Click **Add**

## Using Workspaces with MCP

When you connect an AI client via MCP, you select an organization. The AI client will have access to all tools and resources in workspaces you're a member of within that organization.

Learn more about [MCP Setup](/mcp).
